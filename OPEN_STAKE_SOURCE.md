# Open Stake test deployment

The GitHub Pages workflow builds the public Open Stake demo from:

- Upstream repository: <https://github.com/tanh1c/stake-originals-clone>
- Pinned commit: `7f7065832cae8c898494ca7398f23d4a33a05c17`
- Public path: `/maktub-sdk-demo/open-stake/`

The build changes routing for GitHub Pages and provides a browser-local test balance of
10,000 Byte Coin (BC). It does not add a backend, deposits, withdrawals, or real-money play.
