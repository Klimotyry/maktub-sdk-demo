# Maktub SDK Demo

Публичный статический стенд для Maktub Game SDK `8.0.150`.

## Что внутри

- 31 игра из официального Vanilla JS bundle;
- автономный demo mode без access token и серверных секретов;
- стартовый виртуальный баланс `10 000 BC`;
- сохранение баланса в `localStorage`;
- сброс баланса одной кнопкой;
- автоматическая публикация через GitHub Pages Actions.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## Важно

Стенд использует только виртуальные монеты. Реальные платежи, пополнения и вывод средств не подключены. Для production-интеграции нужны `clientId`, backend-сессия и webhook secret от Maktub; секрет нельзя размещать в GitHub Pages.

Исходная документация SDK находится в [`sdk/README.md`](./sdk/README.md).

## Сборка Pages

Браузерный bundle и медиафайлы SDK хранятся в `vendor/` частями, чтобы их можно
было надёжно загрузить через GitHub API. Workflow проверяет SHA-256, собирает
архив и публикует готовый статический сайт. Никакие секреты для сборки не нужны.
